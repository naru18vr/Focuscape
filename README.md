# Focuscape

**A quieter place to focus.**

25分の集中と5分の休憩を、好きな環境音と一緒に。ブラウザを開き、STARTを押すだけで始められる、登録不要の集中作業アプリです。

## 完成したもの

- 25分のFocus / 5分のBreak。START・PAUSE・RESUME・RESET。
- セッション終了時に次のモードへ切り替え。次のセッションは手動で開始。
- 終了予定時刻を基準にしたタイマー。タブ復帰時にも残り時間を補正。
- Rain / White Noise / Cafe / Ocean / Forest / Fireplaceの6種類の環境音。
- 複数音源の同時再生、個別音量、Master Volume、全体ミュート。
- 音量を滑らかに変更するフェードと、ミックス出力のリミッター。
- 小さな終了チャイム、画面上の終了メッセージ、任意のブラウザ通知。
- 音の設定と実行中・一時停止中のタイマーをlocalStorageに保存。
- PC・タブレット・スマートフォンに対応したダークUI。
- キーボード操作、ラベル付きコントロール、ネイティブ設定ダイアログ、動きを減らす設定への対応。

## 使い方

1. 好きな環境音を選ぶ。最初はRainが選択されています。
2. **START**で25分の集中を開始。
3. 必要に応じて**PAUSE**、**RESUME**、**RESET**を操作。
4. 終了すると5分のBreakに切り替わるため、**START BREAK**で休憩を開始。
5. 休憩終了後、**START**で次の集中へ。

音カードはON / OFFを切り替え、カード下のスライダーで音量を調整します。複数の音を同時に選べます。環境音はタイマーと独立して再生するため、一時停止・リセット・セッション終了後も続きます。スピーカーボタンでまとめてミュートできます。

音はブラウザの自動再生制限に従い、STARTまたは音カードの操作後に再生します。実行中のタイマーをリロードした場合、タイマーは復元され、「環境音を再生」で音を再開できます。

| キー | 操作 |
| --- | --- |
| Space | 開始 / 一時停止 / 再開 |
| R | 現在のタイマーをリセット |
| Tab / Shift + Tab | コントロール間の移動 |
| 左右矢印 | フォーカス中の音量スライダーを調整 |
| Escape | 設定ダイアログを閉じる |

ボタン・入力欄・設定ダイアログ内では、グローバルショートカットが操作を奪わないようにしています。

## 起動方法

Node.js **24.15以降の24系LTS**とnpmを推奨します。22.22.2以降の22系も利用できます。テスト用依存パッケージに合わせた条件です。

```bash
git clone https://github.com/naru18vr/Focuscape.git
cd Focuscape
git switch codex/focuscape-mvp
npm ci
npm run dev
```

[http://localhost:3000](http://localhost:3000)を開いてください。PRをmainにマージした後は、ブランチを切り替えるコマンドは不要です。

本番用にビルドして起動する場合：

```bash
npm run build
npm start
```

環境変数、バックエンド、DB、APIキー、外部音源のダウンロードは不要です。

## 実装上の判断

1. **正確な区切り**：250msごとの表示更新時に`endTime - Date.now()`を計算します。タイマー通知が間引かれても、次の更新で残り時間を補正します。
2. **静かな移行**：FocusとBreakは自動で切り替え、次の開始はユーザーの操作を待ちます。`durations`と`autoStart`をUIから独立させ、将来のプリセット追加に備えています。
3. **音の権利と待ち時間**：Web Audioのノイズ、フィルター、短い波形で生成した音を使用。音源のライセンス確認や外部サーバーへの依存を避けています。
4. **最小限の保存**：設定とタイマーの状態だけをブラウザ内に保存。保存領域が使えなくてもタイマーを利用できます。

保存キーは`focuscape.settings.v1`と`focuscape.timer.v1`です。不正なJSON、未知のバージョン、範囲外の設定は安全な値に戻します。実行中の終了予定時刻は変わらないため、画面更新ごとにlocalStorageへ書き込みません。

### 音源について

6種類すべてが**実録音ではなく、自然音をイメージしたオリジナルの合成環境音**です。Cafeは人の会話を収録したものではなく、帯域を絞ったノイズによるざわめきです。Forestには合成した鳥の声、Fireplaceには控えめなパチパチ音を重ねています。

今後実録音へ差し替える場合、音源ごとの出典・ライセンス・帰属表示の要否を記録し、`AmbientEngine`の音源生成部分を置き換えられます。タイマー・音量・設定の構造はそのまま利用できます。

### 通知について

通知の許可は設定画面で明示的に操作したときだけ要求します。OSやブラウザが通知・音声を制限した場合も、画面上の完了メッセージは表示します。端末がスリープすると、OSによってWebページの実行が停止するため、復帰後にタイマーを補正します。スリープ中の即時通知は保証しません。

検証環境の制限により、ローカルChromiumは起動時に終了し、クラウドブラウザもlocalhostへの接続を拒否しました。このため、**実音の再生・音量変更、視覚的なレイアウト、実ブラウザの通知、axeによる検査の通過は未確認**です。上記React操作テストはjsdom上での検証であり、ブラウザによる検証とは区別しています。

また、この検証環境ではNode.jsのプロセスメモリ情報取得が失敗するため、検証用にインストールしたNext.jsのメモリ計測だけをスキップしてビルドしました。その環境対策はリポジトリのアプリコードや依存パッケージ設定には含めていません。

```bash
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

用意したブラウザテストはPC表示とスマートフォン表示で以下を検証する構成です。

- START・PAUSE・RESUME・RESET、バックグラウンド相当の時間経過。
- FocusからBreak、BreakからFocusへの切り替えと、次の手動開始。
- 設定保存、一時停止・実行中のリロード復元。
- 6音源のON / OFFとミックス状態の保持。
- Web Audio出力をAnalyserNodeで測定し、個別音量・Master Volume・ミュートを検証。
- キーボード操作、設定ダイアログのEscape閉じとフォーカス復帰。
- 保存領域・Web Audioが利用できない場合の動作。
- 通知APIのテストダブルによる、許可要求のタイミングと通知の重複防止。
- 幅320 / 390 / 768 / 1024 / 1440pxの横はみ出し確認。
- axe-coreによるWCAG 2.2 AAの自動チェック。
- 各テスト中の未処理JavaScriptエラー確認。

スマートフォン表示はChromiumでのエミュレーションです。iOS Safari、Android実機、OSの通知表示とスリープ中の挙動は別途実機確認が必要です。自動アクセシビリティ検査はスクリーンリーダーによる手動検証を置き換えるものではありません。
